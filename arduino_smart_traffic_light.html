🚦 Arduino 스마트 신호등 프로젝트

사용 부품

  • Arduino UNO
  • 3색 신호등 LED
  • 버튼
  • 피에조 부저

핀 연결

부품핀
빨간 LEDD11
노란 LEDD12
초록 LEDD13
버튼D7 + GND
부저D8 + GND

동작

버튼 입력으로 신호등과 부저를 제어하는 Arduino 프로젝트

Arduino 코드

const int BUTTON = 7;
const int BUZZER = 8;

bool soundOn = false;
bool lastButton = HIGH;

void setup(){
 pinMode(BUTTON, INPUT_PULLUP);
 pinMode(BUZZER, OUTPUT);
}

void loop(){
 bool now = digitalRead(BUTTON);

 if(lastButton == HIGH && now == LOW){
   soundOn = !soundOn;
   delay(200);
 }

 lastButton = now;

 if(soundOn){
   tone(BUZZER,1500);
   delay(100);
   tone(BUZZER,1000);
   delay(100);
 }
 else{
   noTone(BUZZER);
 }
}
